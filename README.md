## 🌌 Design Philosophy & Inspiration

This portfolio draws structural and interactive inspiration from award-winning creative developer experiences (such as *Agustin Burgos*), re-imagined through a custom **Cyberpunk Dark Mode** aesthetic tailored to my dual journey in **Software Engineering** and **Commercial Outreach Consulting**.

### ✨ Key Technical Features

1. **Hybrid Background Engine (`<video>` + `<canvas>`)**:

   * Combines a looping dark sci-fi HTML5 video stream with a custom interactive particle-node matrix that connects to your cursor/touch in real time and emits shockwave ripples on click.

2. **Multi-Theme HUD Switcher**:

   * Switch instantaneously between `NEON_ANOMALY` (Electric Cyan & Neon Magenta), `CYBER_OVERDRIVE` (Acid Yellow & Crimson), and `STEALTH_OPS` (Matrix Bio-Emerald) using CSS Custom Properties (`:root`).

3. **Interactive Spotlight Glassmorphism**:

   * Every `.cyber-card` dynamically tracks `--mouse-x` and `--mouse-y` coordinates to project a glowing neon border spotlight.

4. **Native Web Audio API Cyber-Synth Widget**:

   * Generates an ambient cyberpunk synthwave arpeggio directly in the browser without relying on external MP3 dependencies.

5. **100% Android, iPhone & Desktop Responsive**:

   * Built with fluid `clamp()` typography, adaptive CSS Grid layouts, touch-event particle support, and a dedicated mobile navigation drawer.

## 🌐 Safe Deployment Guide (Vercel / Netlify / GitHub Pages)

Because this portfolio is **100% original code** tailored specifically to **Divyansh Namdev** with zero copyrighted assets or phishing scripts, you can host it safely on **Vercel**, **Netlify**, or **GitHub Pages** without any risk of account suspension:

1. Push `index.html` and `README.md` to a new public or private **GitHub Repository**.

2. Log in to [Vercel](https://vercel.com) or [Netlify](https://netlify.com) and click **"Add New Project"** -> **"Import from GitHub"**.

3. Select your repository and click **Deploy** (No build command is required since `index.html` is in the root directory).
